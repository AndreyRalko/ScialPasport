# Система "Социальный паспорт студентов" (Django)

Готовый каркас системы с ролевым доступом, карточкой студента, блоками социального паспорта, ИИ-аналитикой, фильтрацией и экспортом отчетов.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_data
python manage.py createsuperuser
python manage.py runserver
```

## Что реализовано

- Аутентификация: вход/выход, ограничение страниц по `login_required`.
- Роли и расширяемость:
  - сущности `UserRole`, `UserProfile`;
  - поддержка расширения ролей через справочник ролей.
- Справочники с мягким удалением:
  - базовый класс `ReferenceModel` + `is_active`;
  - все требуемые типы справочников заведены как отдельные модели.
- Модуль студентов:
  - `Student` с валидацией ИИН (12 цифр), вычисляемым возрастом, индексами по ФИО/ИИН/телефону.
- Блоки карточки студента:
  - `StudentFamily` + `StudentFamilyMember`;
  - `StudentHousing`;
  - `StudentPsychoProfile`;
  - `StudentAcademic`;
  - `StudentMedical` (доступ через permission);
  - `StudentBenefits`.
- ИИ-компонента:
  - `StudentAIAnalysis` (история анализов);
  - кнопки "Сформировать/Повторно проанализировать";
  - вывод профиля, сильных сторон, рисков, рекомендаций, уровней риска/сопровождения, даты и дисклеймера.
- Общая страница "ИИ-аналитика":
  - список анализов;
  - фильтр по уровню риска;
  - выборка студентов в зоне внимания.
- Поиск и фильтрация списка студентов:
  - поиск по ФИО/ИИН/телефону;
  - фильтры по академическим, социальным, медицинским и справочным полям.
- Отчеты:
  - страница отчетов;
  - экспорт в CSV/XLSX для ключевых выборок.
- Журнал действий:
  - `ActionLog`;
  - логин/логаут через сигналы;
  - логирование CRUD операций из view.

## Основные URL

- `/login/` — авторизация
- `/` — список студентов
- `/students/<id>/` — карточка студента
- `/ai-analytics/` — ИИ-аналитика
- `/reports/` — отчеты и экспорт
- `/action-logs/` — журнал действий
- `/admin/` — админ-панель (управление справочниками, пользователями, ролями)
